# 🚢 Ship Management System (Prototype)

A prototype ship management system built with Python + Streamlit + SQLite.

## Features
- Fleet management (vessels, details, status)
- Crew management (contracts, assignment, certifications)
- Voyages & Cargo tracking
- Finance & Voyage Profit/Loss
- Maintenance & Safety drills
- Dashboard with KPIs

## Install
```bash
pip install -r requirements.txt
```

## Run
```bash
streamlit run app.py
```
